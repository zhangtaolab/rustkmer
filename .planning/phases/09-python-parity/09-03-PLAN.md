<objective>
Give the Phase 9 measurement its verdict instrument: a dev-host baseline comparison mode on the existing fresh-worker Python benchmark, reporting both the threads=1 isolation arm and the default-threads user arm against the committed Phase 5 N-free-control baseline.

Purpose: the committed baseline measures the pre-Phase-9 sequential PyO3 pipeline at 32.14 s on the N-free control. Phase 9 must prove a measured win, not assert one, and the contract is exit-code based. `python_bench.py` already reserves exit 1 for exactly this mode, already fingerprints the native `.so`, and already runs every rep in a fresh interpreter — the missing pieces are a configurable thread count per arm, a second (default-threads) control arm, and the comparison itself.

The N-free control is the only parity invariant across D2: it contains no N, so skip-N and strip-and-join agree on it. The real-N arm is timing-only evidence and is labeled post-D2 from this plan forward; committed baseline files are immutable history. This plan produces the harness and its unit tests only — the measured run and its evidence artifact are the phase's final gate in 09-05.

Output: `--threads default|N` worker support, dual N-free-control arms, `--compare-baseline` with host/fingerprint/exact-count guards, the 0/1/2 exit contract, a verdict-matrix unit suite, and the standing bench README update.
</objective>
