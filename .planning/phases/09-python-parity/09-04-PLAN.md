<objective>
Make the D2 semantics change explicit and prove it is unified: give the N-read differential a before/after artifact mode and document the user-visible change in all three places the locked decision requires.

Purpose: D2 changes what Python users see on N-containing reads — 33 chimeric k-mers disappear on the nine-case fixture and the Python total drops from 70 to 37. The WR-04 precedent forbids a silent output change. `PyCounter`'s docstrings are already updated by 09-01; this plan adds the user-facing docs page, the mkdocs navigation and index link, and the `pyo3/README.md` migration note, and it extends `n_read_differential.py` so the Phase 9 re-run can carry the exact before/after counts inside one self-contained artifact.

The differential script already asserts "all cases equal" under `--expect-unified`; today it is RED exactly as the pre-Phase-9 record predicts. What it lacks is the cross-run comparison: `--previous` loads the committed Phase 5 artifact, validates that k/canonical/case names match, and embeds a `before` block while keeping the top-level `cases` as the after state. The actual measured re-run and its committed artifact are 09-05's final gate; this plan builds and unit-tests the mode.

Output: a unified-semantics differential harness with `--previous`, its unit suite, a new N-read semantics docs page wired into the site nav and index, and the README migration note.
</objective>
