## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dense in-memory key -> `.rkdb` v2 bytes | A `u64` key crosses into a 16-byte little-endian `u128` on disk. A non-zero-extending widening changes every byte an existing reader sees. |
| committed fixture -> test verdict | A test verdict derived from static committed bytes tells the reader nothing about the code that produced them. |
