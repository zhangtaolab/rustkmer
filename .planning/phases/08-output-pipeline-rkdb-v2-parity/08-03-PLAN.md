<objective>
Prove that every new counting/output path preserves exact counts, and prove the proof gates can fail.

Purpose: OUT-03 is the exactness contract for the new paths (partitioned tables, end reduction, parallel unstable sort, streaming write). A differential matrix is only trustworthy if its cells are all exercised and if its gates demonstrably turn red when a defect is injected. This plan adds the k x canonical x threads matrix against the pre-refactor reference algorithm, output-boundary disjointness/conservation properties, and a mechanical mutation driver that observes RED for ordering, duplication, and overflow defects and proves the tree is restored afterwards.

Output: an integration matrix test file, a reusable mutation-RED driver with unit tests, a mutation spec, and the recorded RED/GREEN evidence.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| injected source mutation -> gate verdict | a gate that cannot fail is not evidence |
| mutation restore -> working tree | a leftover mutation would corrupt every later measurement |
| differential matrix -> exactness claim | a skipped cell hides a defect |
| engine tables -> output pair buffer | duplication or lost keys become wrong counts on disk |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-11 | Repudiation | claimed RED without observation | high | mitigate | Mechanical driver records exit codes and the expected failure substring per gate; unit tests prove the runner/verdict logic; the evidence doc asserts every gate's observed nonzero exit |
| T-08-12 | Tampering | mutation left in the tree | high | mitigate | Restore-in-finally plus blob-hash equality per mutated file; `git status --porcelain -- src/` asserted empty; named gates re-run green |
| T-08-13 | Integrity | matrix blind spots or vacuous cells | high | mitigate | Explicit 12-cell enumeration asserted; every cell asserted non-empty with positive totals; N-read cell compared against a non-vacuous window count |
| T-08-14 | Integrity | duplicates/lost keys in the output path | high | mitigate | Output-boundary proptest: unique keys, pair count equals unique count, count-sum equals total, strict ascending after sort, filter semantics |
