## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| pipe-exit-status | `grep … \| head -5 \|\| echo fallback` never prints the fallback (head exits 0); masked a real `cargo fmt` failure as success once | advisory | check exit status directly; avoid pipes inside guard scripts |
| zsh-glob-abort | an unmatched glob aborts the ENTIRE compound command (exit 1) — later checks in the same `;` chain silently never ran | advisory | append `2>/dev/null \|\| true` per glob, or split checks into separate commands |
| macos-no-timeout | `timeout` does not exist on macOS zsh | advisory | use the Bash tool's `timeout` parameter |
| fmt-vs-read | `cargo fmt` modified files after they were Read → subsequent Edit failed on stale content | advisory | re-Read target regions after any fmt run before editing |
| two-terminal-sudo | macOS sudo tty tickets are per-tty: a keep-alive in a second terminal does NOT refresh the first terminal's ticket | advisory | single-terminal pattern: foreground `sudo -v`, then background `while true; do sudo -n -v; sleep 60; done &` |
