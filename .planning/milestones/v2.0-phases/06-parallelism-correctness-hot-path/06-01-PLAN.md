<objective>
Make `--threads` actually size the rayon pool and turn the Phase 5 thread-reality gates GREEN, recording the true single-thread baseline.

Purpose: The measured root cause of the v2.0 gap is that `--threads` is a silent no-op: the resolver eagerly initializes rayon's default pool as a fallback argument before `build_global` runs, and the discarded `build_global` error hides the failure. Every later hot-path measurement and the Phase 7 engine depend on working, observable thread control.

Output: A fixed resolver and initialization order in `src/cli/commands/count.rs`, an active pool-size gate with an inverted characterization test, a GREEN thread-scaling artifact with provenance, and the true t1 baseline.
</objective>
